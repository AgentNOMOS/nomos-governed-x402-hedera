# Demo UI — CP-H8 (not built)

Deliberately empty at CP-H1.

When it lands it will be a single self-contained page showing one purchase:
the 402 challenge, the policy decision, the Hedera transaction, the delivered
result, the signed receipt, the HCS anchor, and the HashScan links — with a
"verify this receipt" button that runs the same verification logic as
`tools/verify-receipt.ts` in the browser.

It will show the failure paths too. A demo that only shows the happy path is a
demo of a happy path.
